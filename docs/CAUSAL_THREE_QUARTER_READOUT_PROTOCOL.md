## Frozen three-quarter scaling

For a signed sequence of values `x_1,...,x_L`, define

\[
\mathcal A_{3/4}(x_1,\ldots,x_L)
=L^{-3/4}\sum_{k=1}^{L}x_k.
\]

The exponent is fixed at exactly `3/4`. It is not fitted and no alternative exponent will replace it after results are observed.

For each Stage-M response use the self-dual reference

\[
R_n(q)=\frac{N_n(q)-N_n(1)}{N_n(1)},
\]

and the dimensionless three-quarter amplitude

\[
D_n(q)=\operatorname{sgn}(R_n(q))\,|R_n(q)|^{3/4}.
\]

This is anchored at `D_n(1)=0` and preserves reciprocal symmetry because `N_n(q)=N_n(1/q)`.

## Exact task geometry

The frozen positive motif is

\[
CGCG,
\]

and the composition-matched cyclic decoy generated by the benchmark is

\[
GCGC.
\]

The exact gate must verify, using the unchanged v0.9 operators, that their terminal projective coordinates are reciprocal:

\[
q(CGCG)q(GCGC)=1,
\]

and that their signed phase coordinates have opposite sign:

\[
\log q(CGCG)=-\log q(GCGC).
\]

The Stage-M response is expected to be equal for this reciprocal pair. Therefore the task separates two roles:

- reciprocal-odd phase carries orientation;
- reciprocal-even DHSE response carries geometry relative to the self-dual point.

An even-only representation is a preregistered negative control for this exact reciprocal orientation task.

## Per-window channels

For an ordered window `w=x_1...x_L`, let

\[
\ell_k=\log q_k
\]

for the exact causal prefix trajectory.

### Odd phase channel

For every window record, in this fixed order:

1. `A_3/4(ell_1,...,ell_L)`;
2. `A_3/4(Delta ell_2,...,Delta ell_L)` with zero for `L=1`;
3. terminal `ell_L`;
4. signed value with maximum absolute magnitude among `ell_k`;
5. minimum `ell_k`;
6. maximum `ell_k`.

### Even geometry channel

For every `n=1,...,4`, record:

1. `A_3/4(D_n(q_1),...,D_n(q_L))`;
2. terminal `D_n(q_L)`;
3. minimum `D_n(q_k)`;
4. maximum `D_n(q_k)`.

Also record the three-quarter aggregate of the self-dual residual

\[
\rho(q)=\frac{|q-1|}{q+1}.
\]

No raw million-scale `N_n` value is mixed directly with phase coordinates.

## Local pooling across sequence positions

For each frozen window length

\[
L\in\{3,4,6,12,24\},
\]

compute each per-window feature at every stride-one position. Across positions retain, in fixed order:

1. arithmetic mean;
2. minimum;
3. maximum;
4. signed value with greatest absolute magnitude.

The primary length-4 block is also emitted separately before the multiscale blocks. This preserves a local motif-scale signal instead of reducing the entire sequence to one ordinary mean.

## Channel separation and projections

The phase and even geometry vectors remain separate until after deterministic label-blind projection.

At output budgets `12,24,48`:

- phase-only projects the phase source to the full budget;
- even-only projects the even source to the full budget;
- split phase-plus-DHSE projects each source to half the budget and concatenates the two projected blocks;
- no projection row may contain coordinates from both source channels.

The projection matrices are deterministic Rademacher matrices fixed from declared seeds. The classifier and its train-only standardization remain unchanged.

## Paired background benchmark

The benchmark uses `200` background pairs, producing `400` sequences per seed.

For each pair:

1. sample one background and one insertion position;
2. create the positive sequence by inserting `CGCG`;
3. create the negative sequence from the identical background and position by inserting `GCGC`;
4. reject and regenerate a pair if the opposite target occurs elsewhere and would contaminate the exact contrast;
5. attach one pair identifier to both sequences.

Train/test splitting occurs by pair identifier. Both members of one background pair must remain on the same side of the split. This prevents near-identical backgrounds from leaking across train and test.

## Decision rules

### Technical PASS

Requires all of:

- unchanged v0.9 operator assignment;
- exact `CGCG <-> GCGC` reciprocal coordinate gate;
- odd phase sign inversion and even Stage-M equality;
- deterministic `3/4` aggregation tests;
- pair-isolated train/test split;
- full repository regression and Python compilation;
- deterministic result bundle.

### Three-quarter phase signal PASS

Requires, under paired seed-level differences, phase-only `3/4` to outperform:

1. even-only;
2. the ordinary-mean phase ablation;
3. its sequence-shuffle null.

The split phase-plus-DHSE result is reported separately. Improvement over v0.9, orbital and tetranucleotide baselines is informative but not part of the primary phase gate.

## Interpretation boundary

A positive result establishes only that, on this paired synthetic task, a three-quarter-scaled signed projective trajectory carries reproducible order information beyond reciprocal-even geometry and ordinary averaging. It does not prove biological causation, abiogenesis, DNA decryption or literal execution of the declared Möbius operators by DNA.
