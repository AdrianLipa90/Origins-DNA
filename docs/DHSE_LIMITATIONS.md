# DHSE v0.8 limitations

- The exact theorem is finite: primitive K=6, radius 1/10, lengths 1..4.
- DNA odds summarize declared base partitions inside windows and can discard order.
- Multiscale windows and local differences recover only part of sequence order.
- Equal projection dimension is a capacity proxy, not equal information content.
- The current task is synthetic and motif-based.
- A predictive PASS would not establish that the DHSE operator universe is a biochemical mechanism.
- Origins-Of-Life may motivate a future mechanistic bridge, but it is not silently assumed by this benchmark.
